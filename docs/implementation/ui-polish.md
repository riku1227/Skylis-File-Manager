# ナビゲーションと補助表示の磨き込み

## 場所の右クリックメニュー

ホームのドライブ・ピン留め・フォルダーのカードと、サイドパネルのホーム・ピン留め・よく使う場所・ストレージ・WSLを右クリックすると、「新しいタブで開く」「新しいウィンドウで開く」を選べる。開く先は右クリックした場所で、元のタブはその場所に移動しない。メニュー内では矢印キーとEnterで選択でき、Escで閉じられる。

GPUIの回帰テストで、別の場所への連続右クリック、メニュー選択で渡す場所、新規ウィンドウの初期表示、メニュー表示中の履歴・更新キーを確認した。

## パンくずとスクロールバー

パンくずは従来どおり、6項目以上の場合に先頭と末尾3項目を残す。省略部分に「…」を表示し、欠落を明示する。「…」専用のメニューや操作は追加しない。アドレス編集中は従来どおりパス全体を編集する。

一覧のカスタムスクロールバーは`scrollbar.thumb`の半透明色、幅6px、角丸3pxを使う。バー領域へのホバーとドラッグ中だけ不透明度を1.5倍にする。12pxの入力領域、つまみの位置・高さの計算、ページ送り・Shiftクリック・ドラッグの処理は維持する。ホバーの出入りだけ通知し、動きや独自のフレームループは追加しない。

ピン留め解除の表示・キー操作は[folder-integration-and-pins.md](folder-integration-and-pins.md)、Windows連携バッジは[settings-navigation.md](settings-navigation.md)、詳細ペインの呼称は[display-settings.md](display-settings.md)を参照。第2工程のアニメーションは変更しない。

GPUI回帰試験では、省略表示の5／6／7項目境界とアドレス編集時の非表示、解除ボタンへのTab／Shift+Tabでの到達と退出、Spaceによる解除、ファイル操作へのキー漏れ防止、24pxの入力領域、解除クリックがフォルダー移動に伝播しないことを確認する。スクロールバーの幾何・既存のホイール入力／スクロール試験も維持する。

2026-11-16、Windowsのdebug版を一時APPDATAで起動し、ライト／ダークの省略表示・詳細見出し・解除ボタン・無効バッジを確認した。解除ツールチップ、Tabでのフォーカス表示、行クリック後の表示、Enter／Spaceでの解除とスクロールバーのドラッグも確認した。有効バッジの実状態、タッチ実機は未確認。Windows連携の有効化・復元は実行していない。
