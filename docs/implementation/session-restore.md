# セッション復元

設定の「起動」→「前回のタブを復元」で切り替える。既定はオン。オンなら通常起動時に各ウィンドウのタブの順序と選択タブを戻す。オフならホーム1タブで起動する。通常起動のプロセスでは、オフにした時点で保存中のタブパスを除く書込を要求する（非同期）。不正ファイル保持による保存停止中は元ファイルを変更せず、設定画面に理由を表示する。

ウィンドウの位置・サイズ・最大化状態は設定のオン／オフにかかわらず記憶する。画面UUIDと画面内の相対位置を保存し、同じ画面を指定して復元する。画面がなくなった場合は主画面へ戻し、タスクバーやDockを除いた利用領域へ収める。フルスクリーンと最小化は復元しない。新規ウィンドウは従来どおり現在の窓を基準に配置する。

## 保存と起動

- `settings.conf`と同じフォルダーの`session.json`に保存する。タブ復元設定は既存の設定ファイルへ保存する。
- ウィンドウcloseとアプリquitで、UI上の場所と配置を有界スナップショットにする。保存・同期・置換は専用ワーカーで行い、UIでファイルの存在確認や走査をしない。
- 途中で閉じた窓は除外し、最後の窓を閉じたときはその構成を残す。アプリquitならその時点で開いている窓を保存する。
- 終了時はセッションと設定それぞれの最終書込完了をGPUIの終了猶予（200ms）内で待つ。遅いストレージや強制終了では保存を保証できない。クラッシュ復元は対象外。
- `--path`やShell引き継ぎ等の明示起動要求を優先し、前回の全タブは開かない。配置だけ再利用し、そのプロセスは通常起動のセッションを上書きしない。`--theme`だけの指定はタブ復元を妨げない。
- 設定は未完了の変更がある場合だけ終了時にflushする。設定を触っていない外部起動が、他のプロセスで更新した設定を古い内容に戻さない。
- 消失・アクセス不能のフォルダーは既存の非同期読込でエラーを表示する。復元していないタブへの切り替えは通常どおり使える。書庫タブは書庫を含むフォルダーに戻す。
- 復元した非選択タブの列挙・ドライブ情報取得等は初回選択まで遅延する。起動時に全タブのフォルダーを一斉走査しない。

## 制限と保護

最大8窓・各32タブ、パス4096 UTF-8バイト、保存ファイル512KiB。上限を超える窓・タブは保存しない。非Unicode等の保存できない場所はホームになる。合計サイズ超過は保存エラーとし前の保存ファイルを残す。検索、選択ファイル、スクロール、戻る履歴、フォルダー別表示設定は復元しない。

不正・将来版・大きすぎる保存ファイルはそのまま保持し、この実行でのセッション上書きを止める。設定画面に読込エラーを表示する。保存エラーも、アプリが開いている間に設定画面で確認できる。複数プロセス間の合成は行わず、最後に正常保存したプロセスの構成が優先する。
