# 操作に応答する短い動き

ファイル操作を待たせず、状態変化の手掛かりだけを示す。定数・ease-out cubic・スイッチの共通描画は `apps/explorer/src/motion.rs` にまとめる。既存のスクロール制御は変更しない。

| 対象 | 動き |
| --- | --- |
| 表示設定ポップアップ | 120ms、ease-out cubic、不透明度0→1、トリガー側から6px |
| 設定バックドロップ | 100ms、不透明度0→1、ease-out cubic。パネルとは独立した背景要素 |
| 設定パネル | 140ms、ease-out cubic、不透明度0→1、上から8px。外枠は最終位置に固定 |
| セグメント | 受け皿に選択面を1枚だけ絶対配置。選択番号÷選択肢数をleftの割合に使用。臨界減衰バネ（k=3600,c=120,m=1）で約130ms時点に99%以上到達 |
| スイッチ | ノブとトラック色を同じスカラーで補間。臨界減衰バネ（k=6400,c=160,m=1）で約100ms時点に99%以上到達 |
| カテゴリ内容 | 90ms、ease-out cubic、不透明度のみ |
| 詳細ペイン内容 | 開いたときだけ100ms、ease-out cubic、不透明度のみ。幅は即時に確定 |
| 既存コンテキストメニュー・プレビュー窓 | 従来どおり110ms、ease-out cubic、不透明度のみ |

出現は `with_animation((ID, generation), ...)` を使う。ポップアップとモーダルの世代は閉→開だけで更新する。カテゴリ内容はカテゴリが変わった場合だけ別の世代へ進む。同じカテゴリ内の設定変更では進めない。詳細ペインは開く世代と開いた時刻を保持し、選択変更やタブ再表示で出現を再演しない。初期表示・他タブからの設定継承ではペインのフェードを始めない。

セグメントとスイッチは `with_spring`。安定した部品IDに位置・速度が保存され、目標変更時には現在位置から追従する。初回は目標位置から始まる。独自の反復タイマーやフレームループは増やさない。バネの数学上の収束時間は固定の130/100msではなく、上記は見かけ上の到達時間。十分に収束するとGPUIが最終値に固定してフレーム要求を止める。

入力・フォーカス移動は最初のフレームから有効。閉じる操作は即時。GPUIの `with_animation` / `with_spring` がOSの動作低減を尊重し、有効時は最終状態を描き、アニメーションのフレームを要求しない。

移動は対象自身のrelative位置、選択面とノブはabsolute位置を使い、ファイル一覧・サイドバーのサイズ計算には参加させない。ポップアップの画面内制限と内部スクロールは従来の最終寸法で計算する。有効な画像を読み込み中表示に置き換えない。

フォルダー移動、ファイル一覧・サムネイルの出現、スクロール、タブ切替、ホバー、閉じる動作には追加しない。高頻度の操作を遅らせたり、一覧の再レイアウトを増やしたりしないためである。ファイル走査・デコード・再帰サイズ計算は追加しない。

回帰試験でキー操作、出現世代、カテゴリ内変更、動作低減時のノブ配置とフレーム要求ゼロ、セグメントの最終配置、バネの収束を確認する。実画面での時間精度・連打中の中間フレーム・OS動作低減の切替は別途確認が必要。
