# 検索一致の強調と配下アイコン

2026-11-17〜18、ユーザー指定でArgonとOpus 5.5 mediumへ表示案を相談し、背景マーカーを採用した。青文字＋下線は選択色と同化しやすく、太字による強調は字幅や省略位置を変えるため採用しなかった。

名前の一致部分だけを既存のアンバー色 `match.bg` で強調する。直接の一覧・配下・ギャラリーで共通処理を使い、親パスと名前の編集中には適用しない。文字サイズ・太さ・行高・余白を増やさない。ライトの選択中の青文字を継承するとマーカーとの計算上のコントラストが約3.83:1だったため、`match.fg` のライト値を濃色へ明示化した。ダークは既存の淡色を使う。JSONを正本としてCSS／参照HTML／Rustトークンを生成する。

一致判定は従来と同じ全体の `to_lowercase`。UTF-8の長さが変わるİ・ẞと文脈的な終端シグマを扱い、元の文字範囲へ写像する。部分的な小文字化展開への一致は元の文字全体、結合文字・ZWJ絵文字は表示上のまとまり全体を強調する。非重複一致を使い、接する範囲を統合し、最大128範囲。描画する行だけ計算し、検索語は描画バッチごとに一度だけ正規化する。未確定IME文字への直下フィルター追従は従来どおり。

配下行の「・」「▸」を、18pxの種類別アイコンへ置き換えた。実ファイルのアイコンを問い合わせる `get` は使わず、`get_type` がダミーの `file.<拡張子>`／`folder` キーへ変換する。既存の上限付きキャッシュと単一ワーカーを共有し、画面外の結果には要求しない。取得前や未対応時にも既存のSVGでファイル／フォルダーの形を表示する。直下と同じgap10px・名前開始位置・フォーカスに応じた選択色に揃えた。

GPUIの末尾省略は、元の一致範囲の背景を「…」へ引き継いでいた。背景を持つ末尾のrunだけを分け、省略記号の背景を除く狭いパッチを加えた。通常の文字、Start／Middle省略、フォントと前景色は変更しない。パッチと実行方法は [GPUIパッチ記録](../../vendor/gpui-fast/SKYLIS-PATCH.md) に残した。
