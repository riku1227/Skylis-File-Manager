# 表示設定

承認済みのSol改訂案を実装する。上部のビュー切替と詳細ペインのボタン、下部の密度・隠しファイルのボタンを「表示設定」ポップアップへ集約する。テーマは設定画面に残す。

- このタブ：詳細／ギャラリー、並べ替え（名前・更新日・種類・サイズ、昇順・降順）。キー指定と方向指定は冪等。キー変更時は既存の列ヘッダーと同様に昇順。選択を維持し、手動ソートでは日付グループを解除する。
- このウィンドウ：詳細ペイン。同じウィンドウのタブで共有し、タブ移動時は移動先の状態を使用。新規ウィンドウは従来どおり表示で開始し、永続化しない。
- すべてのウィンドウ：隠しファイルと表示密度。隠しファイルは実行時だけ共有し、再起動後は非表示。密度は既存の保存値と設定画面を共有する。
- 変更は即時反映し、操作後も開いたまま。Esc・×・再クリックで閉じてボタンへ戻る。外側クリックはクリック先を優先。ナビゲーション・タブ変更・他のダイアログ表示で閉じる。
- キーボードからボタンにフォーカスして開ける。各行は矢印、Enter/Spaceで操作。Tabで一覧へ退出。ポップアップのキーを一覧へ漏らさない。
- 画面内に位置を制限し、低いウィンドウでは内部スクロール。隠しファイル表示中は下部に状態だけを示す。
- 既存データと処理を再利用し、追加の走査・画像デコード・再帰サイズ計算をUIスレッドへ載せない。密度の保存エラーを既存Preferencesから表示する。

HTMLコンペのモックは一時成果物のためコミットしない。実GPUI上の共有・入力・配置を回帰テストで確認する。

## 表示上の調整

- 起動ボタンはレイアウトを表すアイコンだけにし、「表示設定」のツールチップを付ける。通常の設定ボタンと図柄を分ける。
- このタブは通常の背景、このウィンドウは青の淡い背景、すべてのウィンドウは抑えた背景で区切る。見出しのアイコンと適用範囲の短い説明を併記し、色だけに頼らない。
- ホームでは表示形式・並べ替え・詳細ペインを、圧縮ファイル内では表示形式を非表示にする。空の区画も省き、ポップアップの高さとキーボードの移動先は表示項目に合わせる。全ウィンドウに効く隠しファイル・密度はホームでも変更できる。

## 検証

Windowsの実画面でライト／ダーク、ポップアップの開閉と開いたままのギャラリー切替を確認。設定保存先は一時APPDATAへ分離した。GPUI回帰試験で320×240を含む配置、実キーバインドとの競合防止、選択を保つ冪等ソート、隠し表示の共有・新規タブ継承、詳細ペインの窓単位共有・タブ移動、外側クリック後のフォーカス、受け入れタブによる旧ポップアップの終了を確認した。macOS実機確認は未実施。
