# 表示設定

上部の表示設定ボタンから、表示形式・並べ替え・詳細ペイン・隠しファイル・密度を即時変更する。テーマは設定画面で扱う。

## 適用範囲と構成

- このタブ：詳細／ギャラリー、並べ替え（名前・更新日・種類・サイズ）。選択を維持し、手動ソートでは日付グループを解除する。
- このウィンドウ：詳細ペイン。同じウィンドウのタブで共有する。新規ウィンドウは従来どおり表示で開始し、永続化しない。
- 詳細ペインのヘッダーは「詳細」とし、表示設定・ツールチップと呼び名を揃える。
- すべてのウィンドウ：隠しファイルと表示密度。隠しファイルは実行時だけ共有し、再起動後は非表示。密度は設定画面と保存値を共有する。
- 項目ラベルは固定幅・通常の太さ・text.secondary。横の適用範囲は小さいtext.mutedで、枠や背景を付けない。グループ間は余白と1pxの区切り線だけ。面はsurface.raised一色とする。
- セグメントの受け皿はsurface.field＋枠、選択面はsurface.chip-selected＋枠・影、選択文字はtext.primary・SEMIBOLD。受け皿・選択面・スイッチのノブ・ポップアップ本体は独立した要素とし、今回はアニメーションを付けない。
- スイッチの「表示／非表示」の重複文字は省き、位置・明度・枠で状態を示す。行全体をクリックできる。
- ホームでは表示形式・並べ替え・詳細ペインを、圧縮ファイル内では表示形式を省く。空のグループは区切り線ごと省く。行IDは0・1・3・4・5（旧方向行2は廃止）。

## 操作

- 並べ替えは1段。選択中のキーだけに↑／↓を表示する。未選択キーのクリックはそのキーの昇順、同じキーの再クリックは方向反転。選択中には再クリックで切り替わる方向のツールチップを付ける。
- ←／→／Home／Endでキーを選ぶ。キーが変わったときだけ昇順へ戻し、端で同じキーに留まった場合は方向を保持する。Enter／Spaceで方向を反転する。
- 変更は即時反映し、開いたまま。Esc・トリガー再クリックで閉じてトリガーへ戻る。閉じる×は置かない。外側クリックはクリック先を優先する。ナビゲーション・タブ変更・他ダイアログ表示でも閉じる。
- ↑／↓／Tab／Shift+Tabで表示中の行を移動し、端のTabで退出する。ポップアップのキーを一覧へ漏らさない。
- キーボードで開いた場合とキー操作時だけ現在行に共通の左枠を表示する。マウスで開いた直後・マウス移動・クリック時には表示しない。
- 起動ボタンはアイコンと「表示設定」ツールチップ。開いている間はツールチップを付けない。
- 高さは表示行の高さと区切り線・ヘッダーから計算する。画面内に配置を制限し、低いウィンドウは内部スクロールする。隠しファイル表示中の下部状態表示も維持する。

## 処理と検証

既存データとPreferencesを再利用し、追加の走査・画像デコード・再帰サイズ計算をUIスレッドへ載せない。密度の保存エラーも既存Preferencesから表示する。

GPUI回帰試験は320×240を含む配置、入力の競合防止、ソート反転・端での方向保持・選択維持、行2を飛ばす移動、×の撤去、入力方法による現在行表示、隠し表示の共有、詳細ペインの窓単位共有、外側クリック後のフォーカスを扱う。実画面の確認結果は作業報告に記載する。

短い操作フィードバックの時間・再生条件・動作低減への対応は [motion.md](motion.md) を参照。
