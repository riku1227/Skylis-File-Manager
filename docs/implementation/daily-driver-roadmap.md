# Skylis File Manager 課題・改善点・機能ロードマップ

日々の主力ファイルマネージャーとして運用できる完成度と、macOS / Apple系アプリ水準のUI・アニメーション品質を目指して整理した棚卸しおよび改善計画です。

## 着手順と状態（2026-11-17更新）

ユーザーの方針は、一つずつ推奨順に実装し、各区切りでOpus 5.5・mediumのレビューを受けること。以下を今後の入口とし、後段のアイデアすべてを直近の実装対象とはしない。

1. **改善リスト整理・Windows CI**：workflow追加。ローカルとGitHub実行の検証状態は[CIの説明](continuous-integration.md)を参照。macOS CI・配布は未実装。
2. **セッション復元**：ウィンドウ配置とタブ構成の復元を実装。タブ復元は設定で切替、サイズ・位置は常に記憶する。[検証と制限](session-restore.md)を参照。フォルダー別表示記憶は未実装。
3. **基本のキー・タブ操作**：タイプアヘッド、Shift＋矢印等の範囲選択、閉じたタブの復元・複製を実装。[操作と検証](keyboard-tab-workflows.md)を参照。キーの自由設定や高度なタブ管理は後続候補。
4. **限定したUndo**：ユーザー判断で保留（2026-11-17）。短い期限や対象操作の限定だけでは安全性を保証できず、現時点では実装しない。本人が希望した場合に再検討する。
5. **再帰検索・条件絞り込み**：名前・種類・拡張子・更新日時の組み合わせに対応。サイズは後続候補。[操作と検証](recursive-name-search.md)を参照。
6. **OS操作・配布整備**：macOSを主用途にする場合はネイティブ操作と標準キーを前倒し。インストーラー・診断情報・macOS CIは独立した区切りにする。

デュアルペイン・同期・重複検索・高度な演出等は後続候補。各区切りを完了する際に、実装・自動テスト・実機確認の状態を別々に記録する。

### 既存改善の扱い

- **実装済み**：表示設定B2相当の整理、Windows連携のカード・横並びボタン・状態バッジ、パンくずの省略表示、ピン留め解除、スクロールバーの整理。詳細は[表示設定](display-settings.md)、[設定画面](settings-navigation.md)、[UI仕上げ](ui-polish.md)。各資料の実機検証範囲を参照する。
- **モーション第1段は実装済み**：メニュー・表示設定・設定モーダルのPresence、スイッチ・セグメント等。[motion.md](motion.md)を正本とし、古いUI調査の「アニメーションなし」を再実装の根拠にしない。
- **実機確認待ちを含む**：macOSのUI表示やネイティブ挙動、モーションの時間精度・連打中の見た目。実装済みでも全OSの実機確認済みとは扱わない。

以下は広い候補の棚卸し。過去時点の行数・状態説明は現行コードとの再照合が必要。

## 現状の到達点と課題の本質

ソースコードおよび設計資料（2026-11-17時点）を確認した範囲では、有界ワーカーによる列挙・アイコン／サムネイル取得、キャンセル制御、復元ジャーナル付きWindows連携、アーカイブ閲覧・作成、および `Presence<T>` によるモーション基盤第1段など、基盤部分は堅牢に実装されています。

一方で、毎日の運用で引っかかりやすい「日常の当たり前（状態復元・タイプアヘッド・Undo・再帰検索・macOSネイティブ操作）」と、配布・保守の足場（CI・インストーラー・クラッシュログ）、そしてビジュアル面の統一感（枠線過多・配色の性格・タイポグラフィ強弱）に改善余地が残っています。

> [!NOTE]
> 本ドキュメントの機能有無および行数の記載はソースコード・設定定義の確認に基づくものであり、Windows実機・macOS実機での全画面動作や体感速度の計測は含んでいません。

## 1. 最優先：主力運用に向けた必須機能・基盤

1. **セッション・表示状態の永続化**
   - 現状: ウィンドウ位置・サイズ・最大化状態、詳細ペイン、タブ構成と各タブの表示形式・並べ替えを`session.json`へ保存し、設定の「起動」でタブ復元をオン／オフできます。隠しファイルと表示密度は共有設定として保存します。外部のパス指定・Shell起動は通常セッションを上書きしません。詳細は[セッション復元](session-restore.md)。
   - 残る改善案:
     - フォルダーごとの表示形式（一覧／ギャラリー）、並べ替えキー・昇降順の記憶（LRU等で件数上限つき）

2. **先頭文字ジャンプ（タイプアヘッド）**
   - 現状: 一覧・ギャラリー・書庫で文字の前方一致ジャンプを実装。800msで入力を区切り、同じ1文字で循環する。IME変換中は移動せず、確定文字で選ぶ。[検証と制限](keyboard-tab-workflows.md)を参照。

3. **アプリ内の「元に戻す」（Undo: `Ctrl+Z` / `Cmd+Z`）**
   - 方針: ユーザー判断で保留。以下の案は検討履歴であり、現在の実装対象ではありません。
   - 現状: 名前変更・移動・削除・新規作成に対するアプリ内Undoは未実装です。
   - 改善案: 直近操作のUndo履歴スタック（まずは名前変更・新規フォルダー／テキスト作成・同一ボリューム移動・ごみ箱移動から）を持ち、競合や外部変更時は安全に失敗を通知する。

4. **再帰検索と絞り込み条件**
   - 現状: 直下と配下を名前・種類・拡張子・更新日時で絞り込み、配下の結果を別セクションへ段階表示します。固定ワーカー、世代とキャンセル、件数・深さ・時間・容量上限、ネットワーク等の明示開始に対応。配下は開く／親で表示／パスコピーが中心です。[検証と制限](recursive-name-search.md)を参照。
   - 改善案:
     - ファイルサイズによるフィルタリング

5. **macOSファイル操作のネイティブ化とショートカット**
   - 現状: [`apps/explorer/src/file_operations.rs`](../../apps/explorer/src/file_operations.rs) のmacOS向け削除・コピー・移動は `/usr/bin/osascript` で Finder に依頼する方式のため、アプリ内進捗表示やキャンセルが効かず、完全削除や競合時置換が無効のままで、自動操作（Automation）権限も必要になります。また、`Cmd+Delete`、`Cmd+↑/↓`、`Cmd+[/]`、`Cmd+Option+V`（移動）、`Cmd+N` などのmacOS標準ショートカットが未割り当てです。
   - 改善案: `NSFileManager`（`trashItemAtURL` 等）や `copyfile` 等のネイティブAPIへ置き換えて Skylis 側で進捗・キャンセル・競合解決を制御し、macOS標準キーバインドを揃える。

6. **配布・CI・保守の足場**
   - 現状: Windows CIを追加しました（[検証範囲](continuous-integration.md)）。Windowsインストーラー、自動／手動の更新確認、panicフックによるクラッシュログ保存、アプリ内バージョン表示は未実装です。macOSビルドもローカル署名のみで公証（Notarization）は未構成です。
   - 残る改善案: macOS CI、リリース成果物・インストーラー生成、クラッシュログ出力と設定画面へのバージョン・診断情報導線の追加。

## 2. 日常操作の拡充

- **タブ操作の強化**
  - 実装済み：タブの複製（`Ctrl+Shift+K` / `Cmd+Shift+K`）、閉じたタブを開き直す（`Ctrl+Shift+T` / `Cmd+Shift+T`）。右クリックにも追加。
  - タブ右クリックメニューの拡充（他のタブを閉じる・右側のタブを閉じる・タブのピン留め）
  - `Ctrl+1〜9` / `Cmd+1〜9` でのタブ切替、タブ数が増えた際に縮む可変幅レイアウト
- **選択操作の強化**
  - 実装済み：`Shift+矢印` とHome／End／PageUp／PageDownによる範囲選択。ギャラリーの列数に対応。
  - 選択の反転、パターン選択（例: `*.jpg`）
- **一括リネーム**
  - 連番付与、文字列置換、日付差し込みをリアルタイムプレビュー付きで実行
- **作成・複製・まとめる**
  - 複製（`Ctrl+D` / `Cmd+D`）、同一フォルダー貼り付け時の自動連番
  - テンプレート付き新規作成、シンボリックリンク／ショートカット作成、「選択項目を新しいフォルダーにまとめる」
- **外部連携・パス操作**
  - 「プログラムから開く」をアプリ内メニューの第1階層に配置
  - 「ここでターミナルを開く」「設定したエディター（VS Code等）で開く」
  - パスコピーの形式選択（ファイル名のみ、引用符付き、`file://`、`WSL` 形式）
- **競合解決ダイアログと転送キュー**
  - 上書き・両方残す（リネーム）・スキップを選択できる統一競合ダイアログ（macOSの置き換え制限解消にも必要）
  - 同時1件制限のファイル操作に対する待ち行列（転送キュー）、一時停止、完了通知

## 3. 一覧・表示・場所とデバイス

- **一覧の列カスタマイズ**
  - 固定4列（名前・更新日時・種類・サイズ）から、列幅ドラッグ変更、列の並び替え・表示切替（作成日時・拡張子・属性・画像寸法など）へ拡張
- **表示形式の拡充**
  - アイコンサイズスライダー（`Ctrl+ホイール` ズーム）、コンパクト一覧、カラム表示／ツリー展開
- **汎用グループ化**
  - 現在はダウンロードフォルダーの日付グループのみ。任意のフォルダーで種類・サイズ・日付によるグループ化を選択可能に
- **ステータスバーの情報充実**
  - 選択項目の合計サイズ、フィルター適用時の件数内訳、現在ドライブの空き容量
- **パンくずナビゲーション**
  - 「…」や各階層セパレーターから兄弟フォルダーへ移動できるドロップダウン（現仕様では意図的に見送り中だが深い階層で有用）
- **ホーム画面の改善**
  - 最近使ったファイル・フォルダー、よく開く場所の自動提案、ピン留め項目の並び替えと別名設定
- **プレビュー・詳細ペインの拡充**
  - Windows側での PDF・動画・音声・Markdown・コードハイライト対応強化
  - 詳細ペインへのEXIF情報・再生時間・ハッシュ値表示
- **圧縮ファイルの利便性向上**
  - 書庫内ファイルの直接プレビュー、パスワード付きZIP対応、`tar`/`gz`/`rar` の読み取り、「ここに解凍」ワンクリック操作
- **場所・デバイス・OS統合**
  - 取り外し可能ドライブの着脱検知と「安全に取り外す」
  - SMB共有ブラウズ・資格情報入力・ネットワークドライブ割り当て、UNC／WSLパスの軽量ポーリングまたは更新ヒント表示
  - OneDrive / iCloud オンライン専用ファイルの状態バッジ表示と不用意な実体ダウンロード抑止
  - アプリ内ごみ箱ビュー（一覧・復元・空にする）
  - Windows連携の拡張（既調査の `IShellWindows` ブリッジによる「フォルダーで表示」対応）、単一インスタンス起動時に既存ウィンドウのタブとして開くオプション

## 5. UI/UX・ビジュアルの磨き込み

初期スクリーンショットおよび [`apps/explorer/src/theme_tokens.rs`](../../apps/explorer/src/theme_tokens.rs) 等の実装に基づく視覚面の改善点です。

- **枠線（ネストしたボーダー）の整理**
  - サイドバー外枠・ドライブカード・一覧・詳細ペイン・詳細内カードと枠線が多重に重なっているため、カード内の枠線を減らし余白と面の明度差で区切ることで視認性と軽やかさを高める。
- **独自性のあるアクセントカラーとライト／ダークの一体感**
  - 現在の `accent.fg`（ライト `#2563eb`）は汎用的な青でテンプレート感が出やすいため、Skylis固有のブランド色またはOSアクセントカラー追従を検討する。
  - ライトはスレート系（`#f5f7fa` / `#0f172a`）、ダークは無彩色グレー（`#191919` / `#242424`）となっており、ダーク側にもごくわずかな同系統の色味を乗せてアプリ全体の一貫性を高める。
- **タイポグラフィの強弱と等幅数字**
  - ファイル名を視覚的主役とし、更新日時・種類・サイズは文字色やウェイトで一段控えめにする。サイズ・日時は等幅数字（tabular numerals）を適用して縦の桁揃えを行う。
- **アイコン質感の統一と素材感**
  - ツールバーの線画アイコンとサイドバーのOSカラーアイコンの混在を整理し、単色線画へ揃える選択肢を用意する。
  - GPUI Fast が持つ Windows Mica / 半透明背景を、パフォーマンスと好みに応じて設定で選べる形を検討する（初期実装の非ガラス方針を尊重しつつオプトイン化）。
- **空状態の表現とトークン整理**
  - 空フォルダー・検索0件・未選択詳細ペインに簡潔なアイコンとガイド文を添える。
  - 角丸（小・中・大）と影（浮き・ポップアップ・モーダル）を3段階のトークンへ統一する。

## 6. モーションシステム（Apple水準の操作感に向けて）

詳細は [`motion.md`](motion.md) を参照してください。

### 実装済み（第1段：`feature/motion-system`）

- 役割ベースの臨界減衰バネトークン（`spring::SNAPPY` / `spring::BRISK` / `spring::SMOOTH`）と遷移定義（`MENU` / `POPUP` / `MODAL`）
- `Presence<T>` による即時論理クローズ＋非インタラクティブな残像フェードアウト（`ghost_shield()` による入力吸収、再オープン時の位置・速度引き継ぎ、OSの動作低減対応）
- 右クリックメニュー・表示設定ポップアップ・設定モーダルへの適用および回帰テスト

### 次の段階（未実装）

1. **タブの並べ替え**: 掴んだタブのポインター追従と、隣接タブのバネによる道空け
2. **ドラッグ＆ドロップ**: 持ち上げ時の影表現、ドロップ先への着地、キャンセル／失敗時の元の位置への戻り
3. **一覧の差分アニメーション**: 作成・削除・名前変更された行のみを短時間アニメーション（件数上限つき、超えた場合は即時）
4. **クイックプレビューの展開**: サムネイル位置からプレビューウィンドウへ繋がる展開アニメーション
5. **拡大縮小（スケール）の検証**: GPUIの `Div` にはスケール変形がないため、描画層で導入可能かの調査
