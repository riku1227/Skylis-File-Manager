# 操作改善（2026-11-15）

ユーザー指定: 別窓プレビュー、Explorer連携、標準的なメニュー、慣性スクロール、控えめなアニメーション、D&D、画像インスペクタ、ピン留めを実装する。

## 設計と実装順

1. プレビューを非モーダルのウィンドウへ移し、元の一覧の選択とキー操作を共有する。画像は既存の有限キャッシュとキャンセル可能なワーカーで取得し、読み込み中も直前の画像を保持する。インスペクタにもサムネイルを使う。
2. メニューはOpus 5.5 medium・Hydrogen High・Astra mediumの独立案を統合する。開く／編集／場所／OS拡張を区切り、内部処理用のサイズ操作を除去。新規作成と名前変更は名前入力・衝突拒否・非同期処理を持つ。
3. ピン留めを設定に保存し、全タブのサイドバーとホームへ反映する。
4. Windowsのフォルダー起動連携は明示的に有効化／復元できる小さなアダプターに置く。直接explorer.exeを実行する外部アプリまで完全に奪取することは保証しない。
5. スクロールはピクセル位置を時間で補間し、連続ホイール入力で速度を繋ぐ。描画周期はディスプレイ側へ追従し、停止後はフレーム要求を止める。OSの視差効果低減を尊重する。
6. D&Dは移動元を半透明、受入先だけを強調する。同一ボリュームは移動、異なる場合はコピー、Ctrlでコピー、Shiftで移動。実際のファイル操作はUI外で行う。

## 検証

名前の不正入力／既存ファイル衝突、移動規則、設定保存、スクロールの時刻・端・中断をテストする。cargo test --workspace --locked、cargo check --workspace --locked、releaseビルド、差分検査を行う。実OS登録の有効化はテストで行わない。macOS・実高Hz表示の未検証範囲は結果に明記する。

## 採用した案

- Opus／Hydrogenのフラットな作成メニューと、Astraを含む3案共通の用途別区切り・単一ハイライト・実在するショートカット表示を採用。フォルダーへの貼り付けはクリックしたフォルダーを保存先とする。
- 名前入力は一覧とギャラリーで同じダイアログに統一。ファイルの拡張子以外を初期選択し、IME確定中のEnterは実行しない。同名は上書きせずエラー表示。
- メニューとプレビューの初回表示だけ110msのフェード。仮想一覧の各行はアニメーションしない。高速ホイール入力の誤分類をなくし、連続入力の補間を最大180msに延長する。
- 画像は同じファイル版のキャッシュから直ちに再利用。プレビュー結果の追加8ms待機を除去。端末ごとの体感速度・実高Hzフレーム時間は未計測。

## 実施した検証

- 最新版: `cargo test --workspace --locked -- --skip shell_icons::tests::windows_type_icons_do_not_require_an_existing_file_or_folder` はアプリ165件、core26件成功。既定のignoredは2件。除外した既存の型アイコンテストはOS Shell呼び出しから戻らず、実行を終了したため未検証。
- デバッグビルド、型チェック、書式・差分検査を実施。Release版は稼働中の旧版を置き換えず、`cargo rustc --release --locked -p explorer -- -o target/release/skylis-interaction.exe` で出力。`-o`による出力先の警告は想定どおり。
- Windows実画面でメニュー、名前入力、別窓テキストプレビュー、プレビューからの矢印操作／Esc終了、画像インスペクタを確認。確認用ウィンドウは終了済み。
- 独立レビューの指摘2件（名前入力キーが一覧へ流れる、登録解除で空キーが残る）を修正し、回帰テスト追加。
- Windows関連付けを実際に有効化する試験、実ドライブ間転送、macOS実機、120Hz以上の実機計測は未実施。外部ドロップのコピー印と送信元の許可操作・完了通知に関する未対応部分は `drag-drop.md` に記載。

## プレビューのタイトルバー統一

- Windowsのプレビューも透明タイトルバーを選び、上端をGPUIで描画する。メインと同じテーマ色とウィンドウ操作ボタンを共有し、Windows側がライトテーマでもアプリのダークテーマに揃う。
- ドラッグ、最大化／復帰、閉じるは既存のネイティブヒットテストを利用する。最小化しないプレビューの設定は維持する。
- `cargo test --locked -p explorer preview_` の5件成功。書式・差分検査、`skylis-titlebar.exe`へのReleaseビルド成功。Windows実画面でダーク配色、最大化、タイトルバーのダブルクリックによる復帰、ドラッグ移動、閉じるを確認した。
