# カテゴリ別の設定画面

設定は左側のアイコン付きカテゴリ一覧と、右側のスクロール可能な設定内容に分ける。外観と表示、フォルダーと一覧、描画とスクロール、開発者向けの4カテゴリで、既存の8設定を扱う。WindowsではWindows連携、macOSではアクセス権限が5番目に加わる。

外観は小さな配色見本から選び、表示密度は標準／コンパクトの行間見本から明示的に選ぶ。同じ表示密度を再度押しても値は反転しない。文言は設定名・動作説明・制約・状態表示に限定し、スローガンやカテゴリの導入文は置かない。

カテゴリはウィンドウごとの一時状態。設定値の保存・全ウィンドウへの反映は従来のPreferencesを使う。保存失敗は右ペインに表示し、成功を仮定するステータスは追加しない。OSの描画タイミング、動作低減、ネットワークのサイズ計算制約も従来どおり扱う。

## 操作

- 左のカテゴリのクリック、上下キーでカテゴリを変更する。先頭と末尾は循環する。
- 数字1〜8は対象の設定へ移動し、テーマは循環、他は反転する。短い画面でも対象行までスクロールする。フッターは設定数を表示し、番号付き設定のないWindows連携などでは数字のヒントを省く。
- 修飾キー付きの数字・Escapeは設定画面で消費しない。
- Escape、完了、背景クリックで閉じ、ファイル画面へフォーカスを戻す。
- テーマ・密度カードは明示的な選択。Tab／Shift+Tabにはカテゴリ移動を割り当てない。
- Windows連携は1件1カード（surface.card＋border.card）。右上の文字付きバッジで状態を示し、有効時は色とドットを併用する。下部の内容幅ボタンは横並び・狭い場合は折り返す。有効化はprimary、復元は通常ボタン。処理・有効条件・文言は維持する。
- Windows連携の状態バッジは12px。無効時も`text.secondary`で説明文と同等以上の可読性を保ち、有効時は`accent.fg`＋ドットを維持する。
- 一般の設定行のホバーは内側余白と角丸を付ける。

## 検証とレビュー

- GPUI回帰試験はカテゴリ変更による設定値不変、密度選択の冪等性、数字キーでの対象行への移動と設定変更、motion/performanceのショートカット、640×360・900×600・480×360でのパネル境界を確認する。既存のモーダル・保存・共有設定の試験も維持する。
- Windowsのリリース実画面で外観・密度の見本、カテゴリ移動、ライト／ダーク切替、装飾文句がないことを確認した。確認用プロセスのAPPDATAは一時ディレクトリへ分離し、利用中の設定は変更していない。
- 親レビューで見つけた「システム」の見本が手動テーマに追従する問題は、WindowAppearanceから配色を解決するよう修正した。
- 配色見本・密度見本は小さな矩形と文字のみで構成し、画像読込やファイル走査を追加しない。macOS実機での表示確認は未実施。

短い操作フィードバックの時間・再生条件・動作低減への対応は [motion.md](motion.md) を参照。
