# キーボード操作とタブの再利用

## 文字入力ジャンプ

一覧・ギャラリー・書庫でファイル名の先頭を入力すると、可視項目の選択とスクロールを移動する。検索フィルターは変更しない。大文字小文字を区別しない前方一致で、800ms以上空くと新しい入力になる。同じ1文字の連続入力では次の一致項目へ循環する。一致なしは現在の選択を維持する。

日本語IMEは未確定文字を小さな補助表示に出し、確定するまで選択を動かさない。候補ウィンドウ用の入力範囲はUTF-16で扱う。入力欄・メニュー・ダイアログ・プレビュー・ドラッグ操作中には一覧ジャンプを実行しない。Space等の既存ショートカットは維持する。ジャンプ文字列256 UTF-8バイト、未確定文字列1024バイトまで。フォーカス離脱・通常選択・ナビゲーションで入力状態を破棄する。

## キーボード範囲選択

Shift＋上下左右・Home／End・PageUp／PageDownで基点から移動先まで選ぶ。折り返して戻ると選択範囲も縮む。ギャラリーの上下移動は列数に合わせる。グループ見出しは選択対象に含めず、可視のファイル順を使う。ホームの場所カードは対象外。検索・アドレス・名前変更等の入力操作を優先する。

## 検証

ヘッドレス描画後の文字入力とShiftキーバインド、日本語・サロゲートの変換／取消、未確定状態の破棄、前方一致・同文字循環・時間切れ・上限を自動テストした。Opus 5.5 mediumのIME状態に関する指摘を回帰テスト付きで修正した。実機IMEの候補位置と各OSのキー配列は未確認。
