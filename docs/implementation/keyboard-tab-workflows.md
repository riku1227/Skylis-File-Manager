# キーボード操作とタブの再利用

## 文字入力ジャンプ

一覧・ギャラリー・書庫でファイル名の先頭を入力すると、可視項目の選択とスクロールを移動する。検索フィルターは変更しない。大文字小文字を区別しない前方一致で、800ms以上空くと新しい入力になる。同じ1文字の連続入力では次の一致項目へ循環する。一致なしは現在の選択を維持する。

日本語IMEは未確定文字を小さな補助表示に出し、確定するまで選択を動かさない。候補ウィンドウ用の入力範囲はUTF-16で扱う。入力欄・メニュー・ダイアログ・プレビュー・ドラッグ操作中には一覧ジャンプを実行しない。Space等の既存ショートカットは維持する。ジャンプ文字列256 UTF-8バイト、未確定文字列1024バイトまで。フォーカス離脱・通常選択・ナビゲーションで入力状態を破棄する。

## キーボード範囲選択

Shift＋上下左右・Home／End・PageUp／PageDownで基点から移動先まで選ぶ。折り返して戻ると選択範囲も縮む。ギャラリーの上下移動は列数に合わせる。グループ見出しは選択対象に含めず、可視のファイル順を使う。ホームの場所カードは対象外。検索・アドレス・名前変更等の入力操作を優先する。

## 閉じたタブ・複製

- Ctrl＋Shift＋T（macOSはCmd＋Shift＋T）：最後に閉じたタブを、元の位置へ再作成して選択する。
- Ctrl＋Shift＋K（macOSはCmd＋Shift＋K）：選択中のタブを右隣へ複製して選択する。
- タブの右クリックにも「タブを複製」「閉じたタブを開き直す」を追加した。複製は右クリックしたタブを対象とする。
- 場所・表示形式・並べ替えを引き継ぎ、現在の窓の詳細ペイン・共有設定に合わせる。検索・戻る履歴・ファイル選択・実行中の処理はコピーしない。
- 閉じた履歴は窓ごとに20件まで。終了すると破棄する。D&Dのタブ移動・切り離し・窓をまとめる操作は履歴に追加しない。最後の1タブを閉じない既存仕様は維持する。
- 保存可能な絶対パス4096 UTF-8バイト、書庫内prefix4096バイトまで。保存できない場所は履歴に残さず、複製操作では理由を表示する。消失・権限不足の場所は既存の非同期読込エラーとして扱う。

すべてメモリ上の既存項目と履歴を使い、入力処理へファイル走査や画像デコードを追加しない。タブの再作成は既存の遅延読込・キャンセルの仕組みを使う。
