# Keyboard and Tab Workflows

ユーザーは文字入力ジャンプ、Shift＋矢印の範囲選択、閉じたタブの復元・複製の実装を承認済み。親が実装しOpus 5.5 mediumにレビューを依頼する。

## 方針

- 一覧・ギャラリー・書庫の可視名で大文字小文字を無視した前方一致ジャンプ。800msの入力間隔でリセット、連続した同じ1文字は次の候補へ循環。入力は256 UTF-8バイトまで。IMEは変換中に選択を動かさず、確定文字で検索する。
- 検索・アドレス・名前変更・ダイアログ・メニュー・プレビューとは競合させない。UI上の既存項目だけを探し、走査やデコードは追加しない。
- Shift＋上下左右／Home／End／PageUp／PageDownで可視順の連続範囲を伸縮。ギャラリー上下は列数ぶん移動。通常移動で基点を更新し、ナビゲーション・項目変化では安全に再解決する。
- Ctrl/Cmd＋Shift＋Tで最後に閉じたタブを再作成。履歴は窓単位・最大20件、パス各4096バイト、終了時に破棄。D&Dによる窓間移動は閉じた履歴にしない。復元は場所と表示設定、元の挿入位置を対象とし、検索・戻る履歴・選択は含めない。
- Ctrl/Cmd＋Shift＋Kとタブ右クリックから複製。複製は元の右隣を選択。履歴と複製はホーム・フォルダー・書庫の場所を扱い、既存の有界・検証付き書庫読込を使う。
