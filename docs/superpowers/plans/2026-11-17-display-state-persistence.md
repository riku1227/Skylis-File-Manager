# Display State Persistence Implementation Plan

ユーザーの追加依頼：詳細ペイン・隠しファイルなどの表示設定も保存する。親エージェントが実装し、指定済みのOpus 5.5 mediumでレビューする。

## 設計

- 隠しファイルは全窓共通の設定値として保存し、再起動にも反映する（既定は非表示）。既存の設定ワーカーを使う。
- 詳細ペインはセッションの各窓に保存する。タブ復元オフでも、再利用する窓のペイン状態を維持する。新規窓は従来の既定値。
- タブ復元オンの場合は、各タブの表示形式（自動／詳細／ギャラリー）と並べ替えキー・方向も復元する。タブ復元オフではタブ固有状態を消す。表示密度は既存の共有設定保存を維持する。
- フォルダー別の記憶表、検索・スクロール・選択・戻る履歴は今回の対象外。
- 旧セッション／設定は追加フィールドの既定値で移行する。ファイルサイズ・窓数・タブ数の既存上限と非同期I/Oを維持する。
