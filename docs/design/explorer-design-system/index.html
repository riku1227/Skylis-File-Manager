Explorer デザインシステム 採用済みモックを体系化

毎日使う Windows / macOS 向けファイルエクスプローラーの UI 規約です。高密度で控えめなモダンさを保ち、OS 間で同じ外観にします。値はすべて採用済みモック concept-1.html / concept-1-dark.html から抽出しており、新しいデザイン案ではありません。

5つの原則

  • 面は不透明の単色。背景ぼかし・白い内縁光沢・装飾影・グラデーションは使わない。面の区別は明度差と 1px の細線だけで行う。
  • 影は機能のためだけ。メニュー・ダイアログ等の浮遊物に shadow.popover のみ。パネルには付けない。
  • ダークは無彩色チャコール。地・面・文字・境界に青みを入れない。青は選択・フォーカス・主要操作のアクセントに限る。
  • 密度は固定寸法で守る。タブ 32 / ツールバー 44 / 行 28（コンパクト 24）/ 情報バー 28 / パネル間隔 6 / サイドバー 200 / インスペクタ 268。フォルダー大見出しと上部の件数・種類フィルター帯は置かない。
  • ファイルのアイコンは OS のもの。ファイル・フォルダー・ドライブは OS から取得したフルカラーを色加工せずに表示。このページの色付きアイコンは仮素材。操作アイコンだけが共通の単色線画。

このページの見方

状態見本は hover・押下・フォーカス等をクラスで固定した静止画で、触っても変わりません。操作できる展示（青いラベル付き）はクリックやキーボードで状態が変わりますが、見た目を確かめるためだけのもので、ファイル操作は行いません。上部の「明暗並列」で状態見本をライトとダークに並べて比較できます。

このページは HTML のリファレンスです。Rust / GPUI 側はまだ実装していません。移し方は GPUI.md、設計意図と検証結果は DESIGN.md を参照してください。

色の役割

色は役割名で使います（例: surface.content → CSS では --ex-surface-content）。各カードの左がライト、右がダークの実値です。名前・値のボタンでコピーできます。半透明の値は、その上に重なる面と合成して見えます。

仮素材アイコンの色 仮素材

モック内の仮 SVG を描くためだけの色です。ダークで紙面色を暗くしているのも仮素材だけの調整で、本番の OS アイコンには色変更を加えません。

組み合わせとコントラスト

実際に重なる組み合わせを WCAG 2.x の相対輝度で計算しました（半透明は下の面と合成）。目標は文字 4.5:1、非テキスト（アイコン・フォーカスリング等）3:1。値は tools/build-tokens.cjs が tokens.json から計算し、tools/verify.cjs がブラウザーの描画色でも照合します。

タイポグラフィ

OS 標準の UI フォントを優先します（Windows: Segoe UI Variable / Yu Gothic UI、macOS: システムフォント / Hiragino Sans）。字形は OS で変わりますが、サイズ・太さ・行高は共通です。基準は 13.5px / 1.45。数値列は等幅数字（tabular-nums）。

状態と優先順位

1 つの要素に複数の状態が重なるとき、塗りは次の順で上位のものだけを使います。フォーカスリングは塗りとは別の層で、どの状態にも重ねて描きます。

  1. 無効（disabled） — 文字/アイコンを text.disabled。ホバー・押下に反応しない。フォーカスも受けない（メニュー項目はキー移動で飛ばす）。
  2. 押下中（pressed） — state.pressed。アイコンボタンは 0.96 倍に縮む。指を離すまでの一瞬だけ。
  3. 選択＋一覧にフォーカス — selection.bg＋selection.border、名前を selection.fg・600。
  4. 選択＋フォーカスなし（非アクティブ選択） — selection.inactive.bg（ダークは枠も）。文字色は通常。他のペインを操作中でも選択が分かる。モックでは色の定義のみで、一覧は常にフォーカス扱い（切替は未実装・未検証）。
  5. トグルオン／現在地 — accent.soft＋accent.fg（トグル）、nav.current.bg（サイドバー現在地）、surface.chip-selected（現在パンくず・セグメント）。
  6. ホバー — state.hover。選択行の上では出さない（選択の塗りが優先）。
  7. 通常

重ねて描くもの: キーボードフォーカス（2px focus.ring）、検索一致マーカー（match.bg）、隠しファイルの減光（名前 text.muted・アイコン不透明度 0.48）は、上の塗りと同時に成り立ちます。

モックとの差（要確認）: モックではトグルオンのアイコンボタンにポインターを乗せるとホバー色が勝ちます（CSS の詳細度による）。上の順序表では「トグルオン」をホバーより上にしています。ネイティブ実装ではこの順を推奨します 追加提案。
