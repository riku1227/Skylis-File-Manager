# Explorer デザインシステム — Prism Canopy Compact

2026-11-15 / v1.0。採用済みモックを体系化したもので、新しいデザイン案ではありません。

## 設計意図（要約）

- **毎日使う道具として目立たない。** 高密度で控えめなモダンさ。ブランド演出・大きいヒーロー・フォルダー大見出し・上部の件数/種類フィルター帯は置かない。
- **面は不透明の単色、区切りは明度差と 1px。** 背景ぼかし・白い内縁光沢・装飾影・グラデーションは使わない。影はメニュー/ダイアログの `shadow.popover` だけ。フォーカスリングは機能として残す。
- **ダークは無彩色チャコール**（地 `#191919`、本文 `#f2f2f2`、補助 `#adadad`）。青は選択・フォーカス・主要操作のアクセントだけに使う。
- **寸法を固定して密度を守る。** タブ 32 / ツールバー 44 / 行 28（コンパクト 24）/ 情報バー 28（全幅・下端固定）/ パネル間隔 6 / サイドバー 200 / インスペクタ 268。
- **OS 間で同じ外観。** フォントだけは各 OS の UI フォントを使う。ファイル・フォルダー・ドライブのアイコンは OS から取得したフルカラーを色加工せずに表示し、操作アイコンだけを共通の単色線画にする。
- **色は役割名で使う。** `surface.content`、`selection.bg` などの意味トークンを使い、部品は値を直接持たない。HTML の今の CSS も、将来の GPUI 実装も同じ名前で対応させる。

## 構成

```
docs/design/explorer-design-system/
├── index.html          リファレンスサイト（日本語・単一ファイル・ネット不要・file:// で開ける）
├── tokens.json         唯一の編集元（値・状態ラベル・旧名・用途・コントラスト組・修正案）
├── tokens.css          生成物（--ex-* の CSS 変数）
├── DESIGN.md           この文書
├── GPUI.md             Rust / GPUI へ移すための対応表と境界
├── tools/
│   ├── build-tokens.cjs  tokens.json → tokens.css と index.html への埋め込み、コントラスト計算、--check
│   └── verify.cjs        Headless Chrome による検証とスクリーンショット保存
└── screenshots/        代表画面・部品画像・verify-report.json
```

`index.html` の `<style id="ex-tokens">` と `<script id="ex-token-data">` は生成ブロックです。表示されている色・寸法・コントラスト比はすべてこの埋め込みデータから描画しているため、HTML 表示値・CSS・JSON の三者はずれません。

### 再生成と検証

```sh
node docs/design/explorer-design-system/tools/build-tokens.cjs          # 生成
node docs/design/explorer-design-system/tools/build-tokens.cjs --check  # ドリフト検査（CI 向け）
node docs/design/explorer-design-system/tools/verify.cjs                # ブラウザー検証＋撮影
```

依存は Node.js のみ（build）。verify は Playwright と Chrome を使い、場所は `PLAYWRIGHT_PATH` / `CHROME_PATH` で上書きできます（既定はこの作業環境のパス）。

## 使い方

- **CSS で使う:** `tokens.css` を読み込み、`var(--ex-surface-content)` のように役割名で参照する。テーマは `<html data-theme="light|dark">`、属性なしで OS 設定に従う。任意の要素に `data-theme` を付ければその中だけ固定でき、密度は `data-density="compact"`。
- **名前の規則:** `<役割>.<対象>[.<状態>]`。CSS 変数は `.` を `-` に置換して `--ex-` を付ける（`selection.inactive.bg` → `--ex-selection-inactive-bg`）。
- **部品の実寸と状態:** index.html の各節に「状態見本」（クラスで固定した静止状態）と「操作できる展示」（クリック・キーボードで変化。見た目の確認用でファイル操作なし）を分けて載せています。右上の「明暗並列」で状態見本をライト/ダークに並べられます。
- **旧変数名から移す:** index.html の「旧変数名の対応表」または tokens.json の各トークンの `legacy` を参照。`--bg-glass` → `surface.chrome` など。ガラス時代の未使用変数（`--border-glass`、`--specular-inset`、`--shadow-canopy` 等）は廃止。

## 状態の優先順位（要約）

塗りは上位 1 つだけを使い、キーボードフォーカスのリングは別の層として常に重ねる。

1. 無効 → 2. 押下中 → 3. 選択＋一覧にフォーカス → 4. 非アクティブ選択 → 5. トグルオン/現在地 → 6. ホバー → 7. 通常

検索一致マーカーと隠しファイルの減光は塗りと同時に成り立つ。詳細とキーボード操作は index.html の「状態と優先順位」「キーボードとフォーカス」。

## 検証結果（2026-11-15）

`tools/verify.cjs` を Headless Chrome（file://、HTTP サーバーなし）で実行し **63/63 合格**。詳細は [screenshots/verify-report.json](screenshots/verify-report.json)。

- **生成物の整合:** `build-tokens --check` 一致、埋め込み CSS と tokens.css がバイト一致、外部リソース参照なし。
- **モックとの一致:** concept-1.html（ライト）と concept-1-dark.html（ダーク）の実描画から読んだ色・寸法・角丸 69 項目がトークンと一致（両テーマ）。
- **CSS 計算値:** 両テーマで 185 個の CSS 変数の計算値が tokens.json と一致。色カード 72 枚の表示値も一致。
- **表示:** 1280×800 / 1100×700 / 390×844 × ライト/ダークで横はみ出しなし。幅の広いサンプルは枠内で横スクロール。
- **操作:** 目次の絞り込み（該当なし表示・Enter で移動）・現在位置の強調、390px の目次ドロワー（開くと検索欄へフォーカス、選択で閉じる）、テーマ切替（ライト/ダーク/システム＝OS 設定に追従、保存）、明暗並列、コピー（通常経路と、Clipboard API・execCommand を失敗させた時の手動コピー用ダイアログ）、タブ（追加/切替/Home/→/Delete/横スクロール）、検索（絞り込み/一致/0 件/解除/Esc）、一覧（クリック/Ctrl/Shift 選択、キー移動のリング、非アクティブ選択、密度 24/28、ソート、グリッド）、メニュー（↑↓・無効項目の飛ばし・Enter・Esc・フォーカス復帰）、ダイアログ（Esc・フォーカス復帰）、Tab でのフォーカスリング。
- **コンソール:** 全ページでエラー・例外なし。
- **撮影:** テーマ切替後は遷移（最長 0.15 秒）を待ち、2 フレーム後に撮影。
- **ギャラリー:** gallery.html にリファレンスへのリンクを 1 行追加。既存の verify-gallery.cjs の全項目を、画像の出力先だけ一時フォルダーに変えて再実行し合格（既存のギャラリー画像は上書きしていない）。
